# Archive Correction Note

While reviewing the archive I found an attribution error: the decision to repaint the spare room had been written up as one person's call, when it was actually the other who made that choice and the first who only documented it.

The entry has been corrected. Attribution matters here — the archive is only trustworthy if each decision is credited to the person who actually made it. A note that misattributes a choice is worse than no note at all.
